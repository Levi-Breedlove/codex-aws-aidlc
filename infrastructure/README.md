# Infrastructure workspace

This folder is reserved for infrastructure-as-code files only when the approved
technical design and a current task require them. It may remain empty.

Its presence does **not** authorize construction, AWS account access,
deployment, spending, or teardown. The PRD owns the approved design, TASKS owns
current work, VERIFY owns observed evidence, and RUNBOOK owns repeatable
operations. Every AWS mutation still requires its separate exact authorization.
The directory itself grants no construction or AWS authority.
